# Brand specs from the flyer master file

Source: `Pizza_JKT.ai` (sent by Yakov on 2026-11-07; Illustrator for iPad, PDF-compatible, US Letter, 1 page).
The file itself is not stored in this repo (24 MB, client's master).

## Fonts (embedded in the file)
| Where on the flyer | Font |
|---|---|
| "CARRY UP TO 4 PIZZA BOXES", the email | **Widescreen** Regular |
| "WITH ONE HAND", "PIZZA JACKET", CONVENIENT / DURABLE / FLEXIBLE / TRANSPARENT, phone, "US PATENT" | **Mundial** Black |
| "PENDING" in the stamp | Mundial Regular |
| Body text ("Specially designed for…") | **Avenir Next Condensed** Regular |
| "TRADE CONTINENTAL INC." | Avenir Next Condensed Bold |
| Step labels, "9 seconds to set up" | converted to outlines (no font data) |

Widescreen and Mundial are Adobe Fonts; Avenir Next Condensed is a commercial Linotype font.
Use the originals for print (flyer). The website uses free Google Fonts that look close:
Archivo (width 125) for headings, Barlow Semi Condensed for body text.

## Colors (CMYK, as set in the file)
| Color | CMYK | Website hex (screen) |
|---|---|---|
| Blue (headings, body text) | C99 M69 Y0 K0 | `#2A498C` |
| Orange ("PIZZA JACKET", stamp) | C0 M78 Y97 K0 | `#E0622F` |

The file has no color profile, so there is no exact CMYK→RGB conversion. The website hex values were
sampled from the printed flyer image and match it visually. For print, use the CMYK values above.
